# Navy Executive Simplified Design System

## Brand Identity
**Concept**: Logística de alta precisión. Sobriedad, confianza y eficiencia técnica.
**Visual Style**: Minimalismo funcional con enfoque en la jerarquía de datos.

## Colors
- **Primary**: #0f172a (Azul Marino Ejecutivo) - Usado para encabezados, botones principales y estados activos.
- **Surface**: #f8fafc - Fondo general para descanso visual.
- **Surface-Container**: #ffffff - Fondos de tarjetas y contenedores de datos.
- **Text-Primary**: #0f172a - Legibilidad máxima para información crítica.
- **Text-Secondary**: #64748b - Para metadatos y etiquetas menos urgentes.
- **Success**: #22c55e - Estados "En camino" o "Confirmado".
- **Error/Alert**: #ef4444 - Para retrasos o cancelaciones.

## Typography
- **Font Family**: Inter (Sans-serif técnica).
- **Scale**:
  - **Headlines**: Semi-bold, tracking tight.
  - **Data points**: Monospaced look for IDs/Plates (Inter con ligaduras).
  - **Labels**: All-caps ligero para secciones de navegación.

## Component Patterns
- **Buttons**: Bordes redondeados sutiles (4px), rellenos sólidos para acciones primarias, outlines para secundarias.
- **Cards**: Sombras planas o bordes de 1px en #e2e8f0 para separar información sin saturar.
- **Inputs**: Bordes definidos, foco claro en azul marino.
